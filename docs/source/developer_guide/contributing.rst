Contributing
============

Development branches from ``dev`` and is merged through focused pull requests.
Before opening a pull request, run the complete test, lint, type-checking, and
documentation suite described in ``CONTRIBUTING.md``.

Public functions, classes, methods, and protocols require exhaustive NumPy-style
docstrings suitable for automatic API reference generation. Coordinate-system
assumptions must be repeated near the code that enforces them rather than being
left only in high-level documentation.
