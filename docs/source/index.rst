GONet Astrometry Calibrator
===========================

``gonet-astrometry`` is an independent, GONet Wizard-adjacent package for
astrometrically calibrating wide-field GONet images from stellar detections and
temporal tracks.

The project is currently in its pre-alpha architecture and data-foundation
phase. The first implementation milestone will establish reliable image,
metadata, and Grid-calibration adapters before source-detection algorithms are
selected.
